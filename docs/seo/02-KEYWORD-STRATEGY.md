## 1. Search Intent Overview & Philosophy

Recruiter and engineering hiring queries follow distinct behavioral patterns:
1. **Navigational Queries**: Searchers already know the name "Vedant Singh" (e.g. from an applicant tracking system, referral, GitHub repo, or resume) and search to verify credibility, past work, and code authenticity.
2. **Specialized Skill & Role Queries**: Searchers look for specific technical archetypes ("Python Backend Engineer", "RAG Generative AI Developer", "FastAPI Automation Engineer").
3. **Project & Solution-Driven Queries**: Searchers seek real-world implementations ("ChromaDB DeepSeek R1 RAG Python", "Mistral-7B Outlook automation", "Streamlit Plotly Random Forest dashboard").

Our strategy avoids keyword cannibalization, doorways, or keyword stuffing. Every targeted term maps directly to a substantial page containing authentic, verifiable code and engineering outcomes.
